# Репетиция защиты StepFlow

На отдельном компьютере открой корень репозитория, запусти Docker Desktop и выполни:

```powershell
docker compose up -d --build --wait
docker compose ps
```

У обоих сервисов должен быть статус `healthy`. Открой http://localhost:3000. Для первой репетиции используй чистый том. Если здесь уже запускали StepFlow, создай отдельный проект Compose через `docker compose -p stepflow-rehearsal up -d --build --wait` при свободном порте 3000.

В Edge или Chrome можно держать три аккаунта в соседних вкладках одного окна. Открой отдельный адрес для каждой роли. Все три адреса ведут на один стенд, а браузер хранит входы раздельно.

- Автор: http://author.localhost:3000/catalog
- Ученик: http://learner.localhost:3000/catalog
- Модератор: http://moderator.localhost:3000/catalog

Если стенд запущен на другом порту, подставь его во все три адреса. На стенде проверки issue #3 используется порт 3063. Сначала зарегистрируй демо-аккаунты. При повторном открытии можно войти по тому же email.

| Имя | Email | Роль при регистрации |
| --- | --- | --- |
| Демо Автор | demo-author@example.test | Автор |
| Демо Ученик | demo-learner@example.test | Ученик |
| Демо Модератор | demo-moderator@example.test | Администратор (демо) |

## Инструкция для показа

Название «Подготовить отчёт по лабораторной». Описание «Собери результаты опыта, объясни вывод и сохрани готовый отчёт». Категория «Учёба», время 15 минут.

| Шаг | Действие | Пункт чек-листа |
| --- | --- | --- |
| Собрать результаты | Запиши результаты каждого опыта в таблицу. | Результаты записаны |
| Сформулировать вывод | Объясни, что показал опыт, и приведи число из таблицы. | Вывод подтверждён данными |
| Сохранить отчёт | Проверь оформление и экспортируй документ в PDF. | PDF открывается |

## Сценарий

1. Автор открывает «Создать инструкцию», заполняет все три шага и нажимает «Отправить на проверку».
2. Модератор открывает «На проверке», пишет «Укажи единицы измерения в первом шаге» и возвращает инструкцию. Автор добавляет уточнение и отправляет её снова. Модератор одобряет публикацию.
3. Ученик ищет «отчёт по лабораторной» в каталоге и открывает инструкцию. Автор заходит в «Статистика и вопросы». В первом шаге по одному открытию и незавершённому прохождению.
4. Ученик нажимает «Не получается?» и отправляет вопрос «Что писать, если измерения отличаются?». Затем отмечает чек-лист и завершает первый шаг.
5. Автор возвращается в своё окно или обновляет страницу. У первого шага теперь одно завершение и ноль незавершённых прохождений. Вопрос остался в истории. Автор отвечает «Запиши оба измерения и укажи условия опыта». Ученик открывает страницу уведомлений и видит ответ.
6. Ученик ставит «Полезно», открывает каталог и выбирает «По полезности». На карточке видны 100% и один голос. Инструкции без оценок идут в конце.

Повтори ручное создание и поиск по словам при выключенной Ollama. Если настройки ИИ заданы, при попытке вызвать ИИ приложение сообщит об ошибке. После неё можно продолжить работу вручную.

Этот сценарий рассчитан на локальный демо-стенд с входом без пароля.
