# Демо-данные

В PowerShell из корня репозитория запусти:

```powershell
$env:STEPFLOW_DEMO_DATA='1'
npm.cmd run dev -- --port 3050
```

Данные добавляются один раз в существующую базу. Повторный запуск сохраняет сделанные изменения. Если один из демо-email уже занят, загрузка завершится с ошибкой, сохранив существующие данные.

На странице входа используй один из email. Пароль в режиме стенда не требуется.

| Email | Возможности |
| --- | --- |
| admin@stepflow.test | Админ-панель, две заявки в очереди, история решений, назначение ролей |
| member@stepflow.test | Свои инструкции во всех статусах, аналитика, вопросы, владение бизнес-командой |
| expert@stepflow.test | Эксперт с Plus, рецензии, участие в команде |
| learner@stepflow.test | Незавершённое прохождение, вопрос с ответом, оценка, участие в команде |

В набор входят комментарий, экспертная рецензия, прочитанные и непрочитанные уведомления, командная инструкция и инструкция с отметкой ИИ. Все демонстрационные материалы помечены словом «Демо».

Для разных аккаунтов в соседних вкладках используй адреса `admin.localhost:3050`, `member.localhost:3050`, `expert.localhost:3050`, `learner.localhost:3050`.
