# StepFlow

Платформа пошаговых инструкций для кейса TASKILLS. Интерфейс и сервер находятся в одном проекте Next.js. Данные хранятся в SQLite на сервере.

## Запуск

Требуется Node.js 24 или новее. Из папки проекта:

```powershell
npm ci
npm run dev -- --port 3050
```

Откройте `http://localhost:3050`. Для проверки сборки используйте `npm run build`, затем `npm run start -- --port 3050`. При сборке Next.js загружает Manrope. Вариант с контейнером запускается командой `docker compose up --build` на порту 3000. Контейнер хранит данные в отдельном томе.

База создаётся при первом запросе в `.stepflow/stepflow.sqlite`. Другой путь можно задать через `STEPFLOW_DB_PATH`. Для переноса базы остановите сервер и скопируйте каталог базы. Файл базы и секреты хранятся отдельно от исходников.

## Сценарий для показа

1. На лендинге откройте демо или зарегистрируйтесь как **Автор**. Создайте инструкцию с нуля либо выберите шаблон. Заполните шаги и отправьте материал на проверку.
2. В другом профиле браузера зарегистрируйтесь как **Администратор (демо)**. В разделе «На проверке» можно опубликовать инструкцию или вернуть её с замечанием.
3. Зарегистрируйтесь как **Эксперт**. Откройте опубликованную инструкцию и оставьте рецензию. При подтверждении в каталоге появляется отметка «Проверено экспертом». После изменения материала экспертные отметки требуют новой проверки.
4. Зарегистрируйтесь как **Ученик**. Отметьте пункты шага, оставьте комментарий, вопрос или оценку. Вопрос увидит автор. Можно сделать форк с указанием исходника.
5. Вернитесь к автору и откройте «Статистика и вопросы» у своей инструкции. Показаны открытия, завершения, остановки и запросы помощи по каждому шагу. Остановка считается после 30 минут без действий на последнем незавершённом шаге. Данные появляются по мере прохождения.
6. В опубликованной инструкции нажмите «Скачать PDF» или «Сохранить офлайн». Офлайн-копии и их отметки доступны на устройстве. Приложение открывает офлайн-библиотеку, когда теряет сеть. Для Service Worker нужен localhost или HTTPS.
7. Кнопка «Встроить на сайт» выдаёт код iframe. Опубликованный материал открывается в нём без входа и проходится по шагам. Отметки iframe относятся к текущему просмотру.

Вход в режиме стенда работает по email без пароля. Сеанс и проверка ролей для действий выполняются на сервере. Роли на стенде выбираются при регистрации. Для публичной эксплуатации потребуется вход с подтверждением и отдельная выдача повышенных ролей.

В старом браузере на том же адресе можно открыть профиль под прежним email и нажать «Перенести старые инструкции». Копии попадут в черновики. Прогресс и оценки прежней локальной версии остаются в её хранилище.

## Умный поиск

Поиск по содержимому и синонимам работает сразу. Для режима «Найти с ИИ» скопируйте `.env.example` в `.env.local`, укажите `AI_BASE_URL`, `AI_MODEL` и `AI_API_KEY`, затем перезапустите сервер. Поддерживается OpenAI-совместимый Chat Completions API. Храните ключ в серверной переменной окружения.

## Где лежит код

- `src/app` и `src/components/redesign` — страницы и интерфейс.
- `src/app/api/workspace` и `src/lib/server/workspace.ts` — API, сеансы, роли и SQLite.
- `src/lib/guide-pdf.ts` — создание PDF со встроенным шрифтом.
- `src/app/offline`, `src/lib/offline-guides.ts`, `public/sw.js` — офлайн-библиотека.
- `src/app/embed` и `src/data/editor-templates.ts` — встраивание и шаблоны.
