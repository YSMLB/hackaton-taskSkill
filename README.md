# StepFlow

Платформа пошаговых инструкций для кейса TASKILLS. Интерфейс работает на Next.js, API — на Go. Профили, сессии, инструкции и прохождения хранятся в SQLite.

## Запуск

Для локального запуска нужны Node.js 24+ и Go 1.26+. Из папки проекта:

```powershell
npm ci
npm run dev -- --port 3050
```

Откройте `http://localhost:3050`. Для проверки сборки используйте `npm run build`, затем `npm run start -- --port 3050`. Команды `dev` и `start` поднимают Go API и Next.js вместе. По умолчанию API слушает порт 8080. Для подключения к уже запущенному API задайте `STEPFLOW_BACKEND_URL`. Вариант с контейнером запускается командой `docker compose up --build` на порту 3000. Compose поднимает два сервиса. Том `workspace-data` с базой подключён к Go. При обновлении запускайте Compose с прежним именем проекта, чтобы использовать существующий том.

База создаётся при запуске Go в `.stepflow/stepflow.sqlite`. Другой путь можно задать через `STEPFLOW_DB_PATH`. Для переноса базы остановите сервер и скопируйте каталог базы. Файл базы и секреты хранятся отдельно от исходников.

## Сценарий для показа

1. На лендинге откройте демо или зарегистрируйтесь как **Автор**. Создайте инструкцию с нуля либо выберите шаблон. При настроенном ИИ можно ввести тему и получить редактируемый черновик. Проверьте шаги и отправьте материал на модерацию.
2. В другом профиле браузера зарегистрируйтесь как **Администратор (демо)**. В разделе «На проверке» можно опубликовать инструкцию или вернуть её с замечанием.
3. Подключите демо-подписку, затем назначьте аккаунт экспертом через «Подписки и команды» из профиля администратора. Откройте опубликованную инструкцию и оставьте рецензию. При подтверждении в каталоге появляется отметка «Проверено экспертом». После изменения материала экспертные отметки требуют новой проверки.
4. Зарегистрируйтесь как **Ученик**. Отметьте пункты шага, оставьте комментарий, вопрос или оценку. Вопрос увидит автор. Можно сделать форк с указанием исходника.
5. Вернитесь к автору и откройте «Статистика и вопросы» у своей инструкции. Показаны открытия, завершения, остановки и запросы помощи по каждому шагу. Остановка отображается сразу по последнему незавершённому шагу. Данные появляются по мере прохождения.
6. В опубликованной инструкции нажмите «Скачать PDF» или «Сохранить офлайн». Офлайн-копии и их отметки доступны на устройстве. Приложение открывает офлайн-библиотеку, когда теряет сеть. Для Service Worker нужен localhost или HTTPS.
7. Кнопка «Встроить на сайт» выдаёт код iframe. Опубликованный материал открывается в нём без входа и проходится по шагам. Отметки iframe относятся к текущему просмотру.

Вход в режиме стенда работает по email без пароля. Сеанс и проверка ролей для действий выполняются на сервере. Роли на стенде выбираются при регистрации. Для публичной эксплуатации потребуется вход с подтверждением и отдельная выдача повышенных ролей.

В старом браузере на том же адресе можно открыть профиль под прежним email и нажать «Перенести старые инструкции». Копии попадут в черновики. Прогресс и оценки прежней локальной версии остаются в её хранилище.

## Умный поиск и генерация черновиков

Поиск по содержимому и синонимам работает сразу. Для режима «Найти с ИИ» скопируйте `frontend/.env.example` в `frontend/.env.local`, укажите `AI_BASE_URL`, `AI_MODEL` и `AI_API_KEY`, затем перезапустите сервер. Для Compose поместите эти переменные в `.env` в корне и выполните `docker compose up -d`. Без провайдера доступны ручной редактор, шаблоны и поиск по словам. Поддерживается OpenAI-совместимый Chat Completions API. Храните ключ в серверной переменной окружения.

## Структура проекта

- `frontend/src/app` и `frontend/src/components` — страницы и компоненты интерфейса.
- `frontend/public` — изображения, иконки и Service Worker.
- `frontend/src/lib` — экспорт PDF, офлайн-хранение и функции интерфейса.
- `backend` — Go API, SQLite, сессии, модерация, команды, уведомления и ИИ. Тесты запускаются командой `npm run backend:test`.
- `frontend/src/app/api` — маршруты, которые передают запросы в Go под тем же адресом сайта. Страница встраивания запрашивает только публичную инструкцию через Go.
- `backend-ts` — предыдущая реализация API и исходные данные примеров. Формат базы и cookie сессии совместимы с Go.
- `shared` — типы данных и поиск по словам.
