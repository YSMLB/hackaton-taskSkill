# StepFlow

Платформа пошаговых инструкций для кейса TASKILLS. Бэкенд написан на **Go (Golang)**, фронтенд — на **Next.js (React 19)**. Данные хранятся в SQLite на сервере с поддержкой WAL-режима и безопасных сеансов.

## Запуск

### 1. Запуск бэкенда (Go)

Требуется Go 1.22 или новее:

```powershell
cd backend
go run .
```

Сервер запускается на порту `8080` (настраивается переменными `PORT` или `BACKEND_PORT`).
Для запуска тестов бэкенда:
```powershell
cd backend
go test -v ./...
```

Собрать бинарник:
```powershell
cd backend
go build -o stepflow-backend.exe .
```

### 2. Запуск фронтенда (Next.js)

Требуется Node.js 24 или новее. Из корня проекта:

```powershell
npm ci
npm run dev -- --port 3050
```

Откройте `http://localhost:3050`. Фронтенд автоматически проксирует запросы к Go-бэкенду на `http://localhost:8080` (или заданному через `BACKEND_URL`).

### 3. Запуск через Docker Compose

```powershell
docker compose up --build
```

- Бэкенд на Go поднимается на порту `8080`.
- Next.js фронтенд доступен на порту `3000`.
- База данных SQLite сохраняется в томе `workspace-data`.

База создаётся при первом запросе в `.stepflow/stepflow.sqlite`. Другой путь можно задать через `STEPFLOW_DB_PATH`. Файл базы и секреты хранятся отдельно от исходников.

## Сценарий для показа

1. На лендинге откройте демо или зарегистрируйтесь как **Автор**. Создайте инструкцию с нуля либо выберите шаблон. Заполните шаги и отправьте материал на проверку.
2. В другом профиле браузера зарегистрируйтесь как **Администратор (демо)**. В разделе «На проверке» можно опубликовать инструкцию или вернуть её с замечанием.
3. Зарегистрируйтесь как **Эксперт**. Откройте опубликованную инструкцию и оставьте рецензию. При подтверждении в каталоге появляется отметка «Проверено экспертом». После изменения материала экспертные отметки требуют новой проверки.
4. Зарегистрируйтесь как **Ученик**. Отметьте пункты шага, оставьте комментарий, вопрос или оценку. Вопрос увидит автор. Можно сделать форк с указанием исходника.
5. Вернитесь к автору и откройте «Статистика и вопросы» у своей инструкции. Показаны открытия, завершения, остановки и запросы помощи по каждому шагу. Остановка считается после 30 минут без действий на последнем незавершённом шаге. Данные появляются по мере прохождения.
6. В опубликованной инструкции нажмите «Скачать PDF» или «Сохранить офлайн». Офлайн-копии и их отметки доступны на устройстве. Приложение открывает офлайн-библиотеку, когда теряет сеть. Для Service Worker нужен localhost или HTTPS.
7. Кнопка «Встроить на сайт» выдаёт код iframe. Опубликованный материал открывается в нём без входа и проходится по шагам. Отметки iframe относятся к текущему просмотру.

Вход в режиме стенда работает по email без пароля. Сеанс и проверка ролей для действий выполняются на сервере. Роли на стенде выбираются при регистрации. Для публичной эксплуатации потребуется вход с подтверждением и отдельная выдача повышенных ролей.

В старом браузере на том же адресе можно открыть профиль под прежним email и нажать «Перенести старые инструкции». Копии попадут в черновики. Прогресс и оценки прежней локальной версии остаются в её хранилище.

## Умный поиск

Поиск по содержимому и синонимам работает сразу. Для режима «Найти с ИИ» укажите переменные `AI_BASE_URL`, `AI_MODEL` и `AI_API_KEY` в окружении Go-бэкенда. Поддерживается OpenAI-совместимый Chat Completions API.

## Структура проекта

- `backend/` — Бэкенд-сервис на Go:
  - `main.go` — точка входа, инициализация сервера и маршрутизация.
  - `internal/models/` — структуры данных, роли, проверки доступа и модели снимка рабочего пространства.
  - `internal/storage/` — SQLite-хранилище на чистом Go (`modernc.org/sqlite`), транзакции, сессии, метрики и обработка команд.
  - `internal/handlers/` — HTTP-обработчики (`/api/workspace`, `/api/search`, `/api/guides/{id}`, `/health`), CORS и валидация.
  - `internal/search/` — интеграция с OpenAI-совместимым API умного поиска.
  - `internal/data/` — начальные посевные инструкции.
- `backend-ts/` — архивная копия исходного TypeScript-бэкенда.
- `frontend/src/app` и `frontend/src/components` — страницы и компоненты интерфейса Next.js.
- `frontend/public` — изображения, иконки и Service Worker.
- `frontend/src/lib` — экспорт PDF, офлайн-хранение и функции интерфейса.
- `shared` — общие типы, данные примеров и поиск по словам.
